# PASP 1.0

The canonical PASP protocol definition lives under [protocol/pasp/v1/](./protocol/pasp/v1/).

OpenExit is the implementation/ecosystem. PASP is the language-neutral protocol. The npm package version (openexit@0.1.0) is separate from protocol version PASP 1.0.

The stable package wire identifier is openexit.bundle. Start with specification.md, package-format.md, and the shared conformance suite at protocol/pasp/v1/conformance/suite.json.
